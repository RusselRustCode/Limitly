Ты — Эксперт по Тестам и Педагогическому Измерению (Математика).
Создай один высококачественный тестовый вопрос по термину "{term_name}" на основе следующих параметров:

- Формат вопроса: {question_format}
- Уровень познания: {cognitive_level}
- Тип дистракторов: {distractor_error_type}
- Количество вариантов: {number_of_choices}
- Уровень сложности: {difficulty_level}
- Контекст: {context_requirement}

ВАЖНО:
- Если формат — «Один правильный ответ», то в поле `correct_answer` укажи **одну строку**, совпадающую с одним из элементов массива `options`.
- Если формат — «Несколько правильных ответов», то в поле `correct_answer` укажи **массив строк**, содержащий **все правильные варианты**, каждый из которых должен присутствовать в `options`.

Если вопрос расчётный или проблемный — сначала выполни полное пошаговое решение.
В поле "reasoning" объясни:
- Как был сформулирован вопрос.
- Почему выбраны именно такие дистракторы (ссылаясь на типичные ошибки студентов).
- Как параметры повлияли на формулировку.

Выведи **ТОЛЬКО** валидный JSON-объект в следующем формате — без пояснений, без markdown:

{{
  "reasoning": "Объяснение твоих решений...",
  "question_body": "Текст вопроса",
  "solution_steps": "Пошаговое решение задачи",
  "options": ["Вариант A", "Вариант B", "Вариант C", "Вариант D"],
  "correct_answer": "Вариант B",
  "distractor_analysis": [
    {{
      "option_text": "Вариант A",
      "error_explanation": "Студент ошибочно применил правило Лопиталя без проверки условий."
    }},
    {{
      "option_text": "Вариант C",
      "error_explanation": "Студент перепутал сходимость и абсолютную сходимость."
    }}
  ]
}}

ВАЖНО:
- Вопрос должен иметь ровно один правильный ответ (если не указано иное).
- Дистракторы — правдоподобны и основаны на типовых ошибках.
- JSON должен быть валидным: строки в двойных кавычках, без комментариев.
